# 🏠 NYC House Price Prediction

An end-to-end Machine Learning project that predicts house prices using property-related features. The model is deployed as a Flask web application for real-time predictions.

## 🚀 Live Demo

A Flask-based web application that allows users to enter property details and receive an estimated house price.

## 📊 Model Performance

* **Algorithm:** Random Forest Regressor
* **R² Score:** 95.29%
* **RMSE:** Low prediction error
* **Task:** House Price Prediction

## 🛠️ Tech Stack

* **Programming:** Python
* **Data Processing:** Pandas, NumPy
* **Machine Learning:** Scikit-Learn
* **Backend:** Flask
* **Frontend:** HTML, CSS
* **Deployment:** Render / IBM Cloud

## ✨ Key Features

* Predicts house prices based on input property features
* Machine Learning model trained using real-world housing data
* Flask-based web interface
* Real-time prediction
* Data preprocessing and feature handling
* Easy-to-use prediction form

## ⚙️ How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/mayuripatil8043-eng/NYC-House-Price-Prediction.git
```

### 2. Open the project folder

```bash
cd NYC-House-Price-Prediction
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Flask application

```bash
python backend/app.py
```

### 5. Open in browser

```text
http://127.0.0.1:5000
```
